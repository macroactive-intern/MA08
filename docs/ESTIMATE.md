Step 4 

    Tests

            1. Measurement tests
                        - Authenticated client can create measurement.
                        - unit_system must be metric or imperial.
                        - Duplicate same-day measurement returns 422.
                        - Different users can create measurements for same date.
                        - Client can list own measurements.
                        - Date filter works with start_date and end_date.
                        - Client can update own measurement.
                        - Update cannot create duplicate date.
                        - Client can delete own measurement.
                        - Client cannot update/delete another user’s measurement.
            
            2. Photo tests
                        - Client can upload JPEG.
                        - Client can upload PNG.
                        - Client can upload WEBP.
                        - Other formats return 422.
                        - File larger than 5 MB returns 422.
                        - Validation checks MIME type, not just extension.
                        - Stored path is generated by system.
                        - Original filename is not used in storage_path.
                        - Client can list own photo metadata.
                        - List does not return binary file.
                        - Delete photo removes DB row.
                        - Delete photo removes file from disk.
                        - Client cannot delete another user’s photo.
            
            3. Coach tests
                        - Coach can view client measurements.
                        - Coach can view client photo metadata.
                        - Non-coach gets 403 from coach measurement endpoint.
                        - Non-coach gets 403 from coach photo endpoint.
                        - Client cannot use coach endpoints.

            4. Auth tests
                        - Unauthenticated users cannot access measurement endpoints.
                        - Unauthenticated users cannot access photo endpoints.
                        - Unauthenticated users cannot access coach endpoints.

Step 7 

    Form Requests / validation

            1. Store measurement request
                        - Rules:
                                measured_at required date.
                                weight nullable numeric.
                                body_fat_percentage nullable numeric.
                                notes nullable string.
                                unit_system required enum: metric, imperial.
                                Duplicate same-day measurement returns 422.
            
            2. Update measurement request
                        - Rules:
                                Same validation as store.
                                Unique rule must ignore the current measurement.
                                Must still block changing date to another existing date for the same user.
            
            3. Store photo request
                        - Rules:
                                photo required file.
                                MIME types only:
                                                image/jpeg
                                                image/png
                                                image/webp
                                Max size: 5 MB.
                                taken_at required date.
                                caption nullable string max 200.
